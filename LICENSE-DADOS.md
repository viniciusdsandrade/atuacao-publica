# Licença dos dados

O código do projeto usa a licença MIT (arquivo `LICENSE`).

Os dados publicados pelo projeto usam a licença
[Creative Commons Atribuição 4.0 Internacional (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/legalcode.pt).

Titular: os contribuidores do projeto.

## O que a licença cobre

- Os arquivos JSON gerados pelo ETL e publicados no site.
- Os registros manuais em `contrib/`.

## Atribuição

Ao reutilizar os dados:

1. Cite o projeto.
2. Cite a fonte oficial de cada registro. O campo `fonte_id` e o campo `url_origem` indicam a fonte.
3. Indique se você alterou os dados.

## Fontes de terceiros

Cada fonte oficial tem os próprios termos de uso.
O catálogo em `docs/FONTES.md` registra a licença declarada por cada fonte, quando existe.
A licença CC BY 4.0 cobre a compilação feita pelo projeto. Ela não muda os termos da fonte original.
