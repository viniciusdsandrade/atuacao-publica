# Código de conduta

Este código se baseia no [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Compromisso

Quem participa do projeto trata as outras pessoas com respeito.
O projeto acolhe pessoas de qualquer origem, identidade, crença ou posição política.

## Conduta esperada

- Discutir dados e fontes, não pessoas.
- Aceitar correção baseada em fonte oficial.
- Dar e receber crítica técnica com cordialidade.

## Conduta inaceitável

- Insulto, assédio ou ameaça.
- Linguagem ou imagem sexualizada.
- Divulgar dado pessoal de alguém sem autorização.
- Usar issue, pull request ou comentário para propaganda política ou ataque a político, partido ou eleitor.

## Aplicação

1. Relate o caso pelo canal privado de segurança do repositório (aba **Security**, **Report a vulnerability**).
2. Os mantenedores analisam o relato em sigilo.
3. A resposta pode ser: aviso, remoção de conteúdo, suspensão temporária ou banimento.

## Escopo

Este código vale em todos os espaços do projeto: issues, pull requests, discussões e revisões.
